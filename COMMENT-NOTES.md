# Implementation rationale

The union filesystem gives precedence to the last filesystem registered. Register the in-memory filesystem last so generation stays in the sandbox and golden comparisons read the generated bytes from memory.

Probe GraphQL support through the installed package's model schema. A package version alone does not establish that capability; both validation and benchmarking use the shared probe.

Sources: [sandbox](src/main.ts), [capability probe](v1/test/capability.ts).
